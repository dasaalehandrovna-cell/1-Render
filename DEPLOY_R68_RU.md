# Деплой R68

## Что деплоить
- Обязательно: `1_FAST_R68.zip` на Render #1 FAST.
- HEAVY не менялся: используйте прежний `2_HEAVY_R65_UNCHANGED.zip`, передеплой №2 для R68 не нужен.

## Проверка пересылки после деплоя
1. Откройте меню пересылки и выберите проблемную пару A/B.
2. R68 сам выполнит Telegram preflight и покажет состояние прямо в окне пары.
3. Если показано `Group Privacy включён`, откройте BotFather → `/setprivacy` → выберите бота → `Disable`.
4. После изменения Privacy Mode удалите бота из уже существующей группы и добавьте заново — Telegram применяет изменение к группе после re-add.
5. Включите `🔄` для A⇄B.
6. Напишите новое обычное сообщение человеком в A и затем в B.

## Что искать в логах
При сообщении, которое реально дошло до бота, должен появиться журнал `forward_ingress_r68` с `targets=1` (или больше).
- Если такого события нет для сообщения из группы — Telegram не прислал update: проверьте Group Privacy / членство бота.
- Если `targets=0` — в runtime нет активного edge для этого source chat id.
- Если `targets>0`, но копии нет — дальше в логах будет конкретная Telegram send/copy ошибка назначения.
